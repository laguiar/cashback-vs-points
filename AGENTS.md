# Description

An advanced cashback vs points calculator that takes into account multiple factors.

## Project definition

- Static website in pure HTML, CSS and Vanilla JavaScript
- No frameworks or libraries
- Hosted on GitHub Pages
- Use the folders `styles` and `scripts` to organize the code
- Use the folder `assets` to store the images
- Responsive design for mobile and desktop

## Design

- Minimalist and modern design
- Use pastel tones colors
- Use a clear and concise typography
- Minimize user's cognitive load and inputs
- Keep the travel theme in mind but don't overdo it
